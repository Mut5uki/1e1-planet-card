# Message From Aliens 解包结果

## 结论
- 游戏里没有「汉字贴图资源」。截图里的中文是玩家在符号下自己写的笔记。
- 真正的「文字」资源是：1448 个 100x100 的外星符号 PNG（按英文语义命名）。
- 用于显示玩家笔记的中文字体已导出：FangZhengHeiTi-GBK-1.ttf（方正黑体 GBK）。

## 目录
- glyphs/     全部外星符号（1448）
- cardgame/   行星牌相关子集
- fonts/      嵌入字体（含方正黑体）
- glyph_names.json / catalog.json / chinese_hits.json
